How to get a Gemini API Key:

  1. Visit https://ai.google.dev/
  2. Sign in with your Google account
  3. Navigate to the API Keys section
  4. Create a new API key
  5. Copy and paste the key above

Note: Your API key is stored locally on your device and is only used to call the Gemini API for content filtering.

Whitelisted Creators

These creators will always be shown, regardless of content.

Blocklisted Creators

These creators will be hidden only during work hours (configured below).

Time-Based Blocking

During work hours: blocklisted creators are hidden AND all other videos (except whitelisted) are validated by AI.

Outside work hours: all videos are shown without AI validation (except ads).
